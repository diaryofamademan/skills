# Changelog

## 0.1.4 — 2026-11-21

Sibling calls wired, under the playbook rule: a skill calls the sibling skills its work needs, by name, at the step that needs them. The four-skill pass shaped this skill at build time, but the procedure itself named no calls — a run could complete without ever taking them. Now they are steps: first-principles at the measure step, game-theory when the constraint is an actor.

## 0.1.3 — 2026-11-19

What a run returns now calls in the writing pass. When a bottleneck run ships in raw operations register, its rates and stage names bury the one constraint verdict the reader has to act on. The pass runs the work-humanizer skill in rewrite mode over the run's return — the goal, the chain map, the constraint verdict, and the exploit, subordinate, and elevate lists — then applies the writing-styles skill's plain rules, and the return is not done until the pass has run on the exact text being delivered. Facts, figures, quotes, names, dates, and statuses never change in the pass.

Stop-the-scroll pass over the README. The opening now starts from the reader's question instead of describing the skill, and the README closes with a Get the skill block pointing to the skill's page on ianbalina.com, where the email form lives. No method changes.

## 0.1.1 — 2026-11-16

Public copy rewritten in plain spoken words; no method changes. Part of the eight-skill plain-copy pass Ian directed on 2026-11-16, after the skill pages were found to read as robotic.

## 0.1.0 — 2026-11-14

First build. Named fix-the-bottleneck at the author's direction before publication: the skill is the procedure, and the name states the job; the method it runs remains Goldratt's Theory of Constraints, credited throughout as the source. The seven-step procedure (state the goal as throughput, map and measure the chain, identify the constraint, exploit, subordinate, elevate, repeat) operationalizes Goldratt's five focusing steps for knowledge-work and agent systems, with Reinertsen's flow math, throughput accounting adapted to work in progress, a four-kind constraint taxonomy (resource, policy, hero, external), and a worked case study of an AI agent fleet. The elevate step defers design decomposition to the first-principles skill and other actors' choices to the game-theory skill; both boundaries are stated in the skill's limits section.
