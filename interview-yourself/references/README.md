# References — interview-yourself

These references support **Interview Yourself**, version **0.1.2**. The main `../SKILL.md` holds the procedure and the gate. These files carry the depth: the worked example the method was distilled from, told in de-identified form, and the five rules as pass-and-fail question pairs you can grade your own sets against.

## Index

- [worked-example.md](worked-example.md) — The public worked example. A production self-interview run: the set that failed wholesale, the three questions that replaced it and were all answered the same day, and the question that had to be rebuilt from math into meaning. Shapes only: no names, no companies, no private figures.

- [question-patterns.md](question-patterns.md) — The five rules as pairs. For each rule, a question that passes and a question that fails, with the reason in one line. Generic subjects throughout: a bakery owner, a retired athlete, a first-time founder.
