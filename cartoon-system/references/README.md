# References

The reference files behind `SKILL.md`.

Read `character-bible-template.md` first: every run starts from a bible, and the template is the bible's shape.

| File | What it holds |
| --- | --- |
| `character-bible-template.md` | The blank character bible: the series rules block (cast rule, locked style block, frame spec, palette, line style), the per-character entry fields (with the eyes as their own field), and the reference-set rules — standing anchors in the bible, working anchors chained inside a piece. |
| `panel-grammar.md` | Image composition only: the panel box and its mechanical mount, character placement and scale discipline, backgrounds, one idea per panel, and how the grammar adapts from a carousel page to a video scene. |
| `text-layers.md` | The three optional text layers behind their flags — `headline`, `caption`, `signature`, all off by default — what off means (clean image, no reserved space, headroom only when asked), and the rules each layer follows when its flag is on. |
| `drift-check.md` | The per-panel checklist in full: character identity, the eyes, the cast rule, the continuity block against prior approved panels, box and padding, line style, background, invented text — and the fail procedure: regenerate, strengthen the style block on the second failure, re-check the chain when an early panel changes. |
| `worked-example.md` | One public series — a fox explaining game theory in a launch carousel — through the whole procedure: the bible in summary, three panels, the chaining in practice, one eye-drift failure and its regeneration, and the assembly with all three text-layer flags on. |
