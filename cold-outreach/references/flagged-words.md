# Flagged words

"Write plainly" fails as an intention. Every drafter believes their draft is plain. It works as a list: a short set of words that fail on sight, swept for mechanically in the judge pass. A hit fails the email unless the run justifies the word in one line — some words are the recipient's own vocabulary, quoted back, and that is a justification. Everything else gets the plain word.

## The list

| Flagged | Say instead |
|---|---|
| remit (the noun) | job, area, part |
| utilize | use |
| leverage (as a verb) | use |
| facilitate | help, run, set up |
| commence | start |
| endeavor | try |
| ascertain | find out |
| pertaining to | about |
| in regards to | about |
| synergy, synergies | name the actual gain, or cut |
| holistic | whole, or cut |
| robust (about an offer or product) | strong, or name the fact |
| streamline | cut steps, or name the steps cut |
| ecosystem (when it means a market) | market |
| at this time | now, or cut |
| going forward | from now, or cut |
| in order to | to |
| due to the fact that | because |
| a number of | some, or the number |
| individuals (for people) | people |

## Rules for the list

- **It is a floor, not a ceiling.** The plain-words rule still applies to everything not listed. The list exists for the words drafters reliably fail to notice in their own text.
- **Extend it with your own record.** When a word draws a correction — from a reviewer, a recipient, or your own later read — it joins the list. A list built from one operator's corrections is worth more than a longer list copied from anywhere.
- **Register, not spelling.** The failure these words share is register: they belong to business letters and committee documents, and a cold email written in that register reads as a template before its second line. A word in the recipient's own job title or quoted phrasing is exempt — matching their language is research, not register.
