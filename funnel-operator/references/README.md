# References

The depth material for the funnel-operator skill, version **0.6.0**. `SKILL.md` carries the procedure; these files carry the format templates in full, the channel config template, the research module, the podcast module, the Shorts stage, the blog module, the scoreboard module, the three distribution modules, and a worked example it points to.

| File | What it holds |
| --- | --- |
| `formats.md` | The four format templates — Story A (second person, one narrator), Story B (dialogue, several voices), Explainer (reframe, mechanism, walk, application), Retelling (the complete story) — each with its promise, structure, chapter rhythm, word budget, voice, music rule, visuals, title formulas, and failure modes, plus the reference video each was reverse-engineered from |
| `channel-config-template.md` | The blank `CHANNEL.md` template: every field a channel config carries — identity, position, audience and entry points, format menu, style bible pointer, voice spec, funnel endpoint with the exact call-to-action words, cadence and budget, channel guardrails, and the optional Podcast block — with a note on how to fill each field |
| `podcast-module.md` | The optional podcast module: every episode also publishes as a podcast episode on a feed the channel sets up once — the gate rule it rides, what it produces per episode, the one surface-neutral spoken call to action, the feed setup stage, and its verification items |
| `shorts-module.md` | The Shorts stage: an episode's two or three hand-picked cuts, chosen at the script stage on a stand-alone test, rebuilt natively in vertical in the same production pass, gated with the episode, and released staggered — discovery only, judged on movement to the long episode, never on views — with the mass auto-clipping ban and its verification items |
| `blog-module.md` | The blog module: every episode also becomes a post on the business's own site, built from the script, the stills, and the transcript at the packaging stage — winning title as headline, chapters as headings, the episode embedded, one definition box, one call to action and no second capture offer, the transcript below the article — gated with the episode, published in the same pass as it goes public over the static Pages route (the approved draft rendered into the site's layout, index and sitemap updated, deployed with the site, verified live), and judged on funnel actions, not traffic — with the newsletter rule and its verification items |
| `scoreboard-module.md` | The scoreboard module: stage 9 stood up as two scheduled briefings — a daily brief and a weekly review — over verified sources (platform analytics, the podcast dashboard, the site's beacon and zone traffic, endpoint completions counted by their tested signature), each run carrying the playbook pass (the funnel decomposed, the binding constraint named, a recommendation the evidence supports) and the weekly closing an optimization loop the next weekly judges — a briefing with numbers and no pass is a failed run; the weekly also runs the research refresh and the backlog re-rank |
| `research-module.md` | The research module: the channel's standing market and content research, run before the backlog is first scored, at stage 1, and at every weekly read — what is performing on the platform in the niche, search demand in the audience's own phrasing, what is performing on the channel's other platforms, and buyer demand signals with the channel's own deal flow read first — written as dated research notes the topic scores cite, with the re-rank and refill rules; the failure it prevents is scoring topics on judgment alone |
| `linkedin-module.md` | The LinkedIn distribution module: posts and document carousels built from the episode's materials, prepared at packaging and gated exactly with the episode — the browser route as the default (the member-posting API is partner-gated), the API route only where a channel legitimately holds approved access, the live post read back and its URL logged |
| `x-module.md` | The X distribution module: a post, a thread re-cut from the episode's chapter arc, or a long-form post, one shape per episode — posting through the API on a paid tier via the account's own app, or through the browser — gated exactly with the episode, the live artefact read back whole, its URL logged |
| `instagram-module.md` | The Instagram distribution module: feed posts, reels from the episode's Shorts cuts, and carousels from its cards — posting through Meta's Content Publishing API for Business and Creator accounts connected to a Page, or through the browser (a personal account cannot use the publishing API) — gated exactly with the episode, the live post read back, its URL logged |
| `worked-example.md` | One episode carried through all nine stages at summary depth: the Hidden Worth pilot's first Story A — topic and scores, script outline with chapters, storyboard scenes, packaging, the publish gate, and the numbers read |
