# References

The depth material for the due-diligence skill, version **0.2.10**. `SKILL.md` carries the procedure; these files carry the source map, the grading discipline, and the output format it points to.

| File | What it holds |
| --- | --- |
| `the-sources.md` | Every module's sources: what they carry, how to reach them, and how far to trust them — primaries, official mirrors, and leads, including the sources that do not exist |
| `verification-and-grading.md` | The status taxonomy, the two-identifier identity rule in full, outcome weighting for legal items, the red-flag rubric, and the base rates that keep a fact sheet honest |
| `fact-sheet-format-and-example.md` | The fixed fact-sheet format, and a worked example of claim verification catching a fabricated biography from public sources |
| `shell-company-indicators.md` | The shell-company indicator catalogue for the entity module: weighted signs across registration, officers, operations, financial, and structural categories, scored as a cluster, with the two counter-errors named |

Reference checks are not documented here. They run the sibling `reference-checks` skill — witness verification, the question bank, and answer grading live there, as the single source.
