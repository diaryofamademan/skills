## 0.1.0 — 2026-11-23

First release. The skill is the router for the Made Man Playbooks: given a substantive task, it names the task in one sentence, classifies it against the roster's trigger conditions, selects the skills that match — recording every consideration, ran or skipped, with its reason — runs the selected skills in the collection's fixed order (understand, decide, position, plan, say), merges their outputs into one deliverable under the skills' own boundary rules, runs the writing pass, and closes with the playbook line naming which skills ran and what each one changed.

The release carries the full roster of sixteen playbook skills with their triggers, inputs, and hand-offs; the guardrails that keep the router honest — it stands down on trivial tasks, never runs a skill as decoration, never overrides a selected skill's own gates, and never invents a skill that is not in the roster; and a worked example generalized from a real run, in which six skills decided which of two video channels a founder should build first, and the run's largest finding was a skill the roster did not have yet.

Built in publish shape from the first draft: output contract, worked example, limits and boundaries, icons, and a verify script that checks, among the package's own files, that every skill named in the roster exists on disk.
