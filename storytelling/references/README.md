# References

| File | What it holds |
|---|---|
| `lessons.md` | The evidence base: lessons grouped by where they apply — the hook, structure and arcs, scenes, endings, titles and packaging, sharing — each lesson carrying its evidence label (measured, practitioner, framing, platform-declared, or observed) and its source. Updated over time as the user's own results confirm or rewrite lessons. |
| `storyboard-method.md` | The scene-card method in full: what a card holds, the function test applied card by card, how a card set becomes a storyboard a producer can build from, and a three-card example set. |
| `worked-example.md` | One public story — "Your life as a founder sitting on a goldmine" — taken through the whole procedure: arc choice, structure outline, the hook's first thirty seconds, three scene cards, and the ending. |
